## Business contracts

- **Crawl:** select the actual new job, not a predicted UUID. Its planned scope
  must equal the authoritative initial API-section resources; collected pages
  must stay in that scope, and completed collection must cover it exactly.
  Admission, ongoing collection and successful completion remain distinct.
  Starting an additional crawl or modifying existing work is unauthorized.
- **Create monitor:** require the requested page, exact authorized email scope,
  enabled notifications and calendar-daily recurrence. Broad unjudged markdown
  tracking is a valid alternative; neither exact filter prose nor inline diffs
  are mandatory. Reviewed contradictory filtering fails; unknown active filtering
  needs adjudication. Staged notification setup and an optional initial check
  are supported without authorizing changes to preexisting monitors.
- **Pause and run:** pause the identified failing monitor before creating the
  healthy monitor's actual manual child check. Already-paused state is valid.
  Additional checks, look-alike changes, collateral target configuration and
  damage followed by restoration remain failures.
