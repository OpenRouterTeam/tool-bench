Contracts stop requiring the reference's exact route or a literal quantity
substring. Both use full committed-history preservation with cause-scoped
controller effects and actual child identities.

pods, not only desired state. Remediation must precede both the created note and
incident resolution. Existing notes, the staging incident/namespace, unrelated
incidents/workloads and target urgency remain protected. Multiple truthful notes,
extra observations, acknowledgement and full-Deployment update plans are tested.

reconciler, not certification of real-cluster scheduling or rollout.

quantities. The matching Sentry issue must be plainly resolved only after the
memory limit holds; next-release deferral is not completion. CPU, image, replica
count, other metadata and other workloads/issues remain protected, including
restored collateral mutations.

quantity parser. Unsupported quantity evidence is an evidence/environment
problem, not a fabricated numerical model failure. Ordering now detects
transitions across all selected action records; additional notes cannot disable
the ordering check by making the action selection non-singleton.
